# Round 1 visual and functional comparison

**Captured:** October 26, 2026  
**Reference:** Signed-in Jobber session in Chrome at secure.getjobber.com  
**Replica:** http://127.0.0.1:4321  
**Viewport:** 1523 × 832 CSS pixels for both

## Scope and evidence

All 19 requested reference screens and all 19 matching replica screens are saved as JPEGs in the screenshot folders below. Each file is 1523 × 832. The requested screenshot content is raw and unredacted: no redaction script, mask, or cover was applied. The reference exports were sized to the requested viewport after capture; the replica captures came directly from its browser viewport.

This round covers the visible viewport, route navigation, global menus and drawers, table and calendar structures, and the settings subpages shown in the paired captures. It does not cover content below the captured viewport or submit create, send, billing, booking, or save flows. The live and replica data sets differ, so record counts, names, dates, statuses, and amounts are not treated as visual parity targets. Opening the live Activity feed changed the header unread indicator from 59 to 0; no other live record was submitted or changed.

The reference DOM/style export is [ROUND_1_REFERENCE_DOM_STYLES.json](ROUND_1_REFERENCE_DOM_STYLES.json). It contains exact computed CSS values and viewport rectangles for selected visible nodes, a tag/attribute-only tree for the page body and five key regions, and captured SVG viewBoxes and shape attributes. The export records 31 computed-style nodes, five key DOM regions, 43 SVG elements and 56 path/shape records from the final Home view with the Settings menu open. It deliberately omits page text and record values.

## Summary

The replica already has a coherent Jobber-like shell, route navigation, seeded list screens, a calendar, and working menu/drawer entry points. The largest gaps are the global shell dimensions and typography, missing or simplified screen content, and incorrect overlay geometry. These differences repeat across most of the 19 captures and should be corrected before polishing individual icons.

## Round 2 implementation order

1. **Correct the shared shell:** 60 px header, 188 px sidebar, 24 px workspace inset, 14 px Inter body, 36 px Jobber/Poppins titles, reference palette, logo and vector icons. This fixes alignment on all 19 screens.
2. **Restore page hierarchy and controls:** workflow card metrics; one-row schedule toolbar; dashboard callouts; list-specific filters/columns; dense report catalog; expense and timesheet banners.
3. **Complete settings pages:** reduce the nested settings rail to the live width, implement Client Hub and booking options, and restore Account and Billing cards/actions.
4. **Match overlays:** 410 × 73 px Create menu, 421 px drawers without the local dim scrim, and the compact 288 × 397 px Settings menu.
5. **Use the proper data adapters:** keep account-specific values out of visual fixtures. Validate workflow, calendar and table structures with representative local records while keeping row content independent from the live account.

## Functional verification notes

The replica’s primary routes opened successfully during capture. Its Settings subnavigation reached Company Settings, Client Hub, Requests and Bookings, and Account and Billing. The Create menu, notification drawer, Message Center drawer, and Settings menu all opened. The list/calendar screens rendered local data and visible filters. This round did not submit any form or test create/send/save side effects; the missing controls and alternate empty states above are based on the visible live-versus-replica UI and route content.
